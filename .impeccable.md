## Design Context

### Users
Siswa, guru, wali murid, dan admin sekolah menggunakan AkademiHub Mobile untuk akses data akademik (jadwal, nilai, tugas, materi, rapor, absensi, ujian), keuangan SPP, PPDB, BK, EWS, Insight 360°, notifikasi, forum, dan profil perangkat. Mereka membutuhkan akses cepat dan responsif saat mobile, dengan fokus pada kebutuhan harian siswa/guru/wali serta pengelolaan admin sekolah.

### Brand Personality
Professional, modern, trustworthy, and education-focused. Voice is clean, clear, and helpful with a gentle educational tone.

### Aesthetic Direction
Minimal, clean, card-based layouts with responsive grids, ample whitespace, and role-specific dashboards. Uses Flutter's Material design with custom theme. References typical Indonesian school apps and modern edtech UIs. Avoid cluttered admin backoffice style.

### Design Principles
- Responsive-first: Adapt to phone, tablet, and foldable screens using constraints and responsive utilities
- Role-based dashboards: Simplify view based on user role
- Fast loading and offline-first capability where possible
- Clear error states and retry UX
- Accessibility: Proper contrast, readable text scaling, touch targets
- Consistency: Follow existing pattern in login, tenant selector, and main shell
